# 콘텐츠 근거 · 2026-10-02

## 제작자 이야기

사이트 제작 요청에서 사용자가 직접 제공한 사실: 중학교 2학년 아들을 위해 시작, 아들의 반복적인 사용 피드백을 받아 개선, 재미와 효과를 함께 추구, 급수 정복까지 지속 개선할 의지. 아들의 직접 인용·성적·합격 실적은 만들지 않았다. ‘업데이트는 계속됩니다’는 제작자의 다짐이다.

## 앱 기능

`hanja-study-app`의 최신 README/CLAUDE, 2026-10-01 출시 계획과 hard-paywall ADR, FSRS 서비스·시험 알림 구현·어휘 파이프라인을 참고했다. 과거 문서의 무료 무제한 정책과 한자별 생물 수집 기획은 사용하지 않았다. iOS/Android 정식 출시와 결제는 준비 중, 공개 웹 베타의 주소는 기존 것을 유지한다. 모바일 알림을 웹 지원으로 표시하지 않았다.

## 학습 원리

- [FSRS 공식 설명](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/ABC-of-FSRS): 학습 기록으로 기억 상태를 추정해 복습 시점을 정한다. 특정 알고리즘 버전을 ‘최신’이라고 단정하거나 시뮬레이션 효율 수치를 앱의 효과로 전용하지 않았다.
- [Roediger & Karpicke, 2006](https://pubmed.ncbi.nlm.nih.gov/16507066/): 회상 연습과 지연된 기억 검사에 관한 연구. 앱 자체를 검증한 연구가 아니다.
- 어휘 기반 사전: 한국어기초사전·표준국어대사전. 웹페이지의 설명/명확/문명 풀이와 예문은 사이트용으로 작성한 예시이며 사전 문장을 인용한 것이 아니다. 日+月은 기억을 위한 연상이며 역사적 자원 해설로 주장하지 않는다.

## 이미지와 글꼴

호랑/동료 캐릭터는 앱 `flutter_app/assets/characters/`의 승인된 기존 자산을 그대로 WebP로 변환했다. 생성 모델·소유권 이력을 새로 만들어 쓰지 않았으며, 원래 근거는 앱 `docs/character/RIGHTS_LEDGER.md`이다. 각 배포 이미지의 `.webp.json`에 개별 출처를 기록했다.

학습 카드 이미지는 앱 `test/golden/goldens/collection_card_art.png`의 개발 화면이다. 사이트에 개발 예시라고 표시했다.

- Jua: https://github.com/google/fonts/tree/main/ofl/jua
- SUIT: https://github.com/sun-typeface/SUIT
- 글꼴은 SIL OFL 1.1이며 라이선스 전문을 `public/assets/fonts/`에 함께 배포한다. 문서/스크립트에 필요한 문자로 WOFF2 서브셋을 만들었다.


## 실제 앱 화면과 제품 영상 · 2026-10-03

공개 웹 베타의 실제 8급 체험 세션을 Phi Agent Space에서 직접 조작·촬영했다. 퀴즈, 획순/연상/어휘, 이야기, 도감, 홈 화면 5종과 36초 가로·세로 영상을 배포한다. 학습 결과를 합성하지 않았다. 배경 음악은 제작 스크립트의 수식으로 만든 원본이며 외부 음원을 사용하지 않았다. 세부 제작·검증 근거는 [제품 쇼케이스 기록](review/product-showcase-2026-10-03.md)을 참조한다.

## 앱 손글씨 체험 재사용 · 2026-10-03

`flutter_app/assets/hanzi/明.json`·`木.json`의 획 윤곽·중심선을 그대로 사용한다. `hanzi_painter.dart`의 GlyphFit 값을 실제 Flutter 테스트에서 추출했다. `stroke_scorer.dart`의 32점 리샘플링·이산 Fréchet·방향·0.22 허용치를 JS로 옮기고 60개 사례를 실행 결과와 대조했다. ARPHIC Public License 전문과 원본 출처는 `public/assets/hanzi/`에 함께 배포한다. 앱의 사용자 기록·FSRS·구매 상태는 연결하지 않는다.
