# 어흥!한자 소개 사이트

## 제품과 목적

썬웍스(Sunworks)의 한자 학습 앱 **어흥!한자**를 소개하고, 방문자가 실제 웹 베타를 시작하도록 돕는다. 소개 사이트는 `hanja-app.sunw.kr`, 기존 웹앱은 `https://bryannamd.github.io/hanja-web/`이다. 기존 웹앱의 저장소와 배포는 변경하지 않는다.

## 사용자 확인 사항 · 2026-10-02

- 학생과 부모 모두에게 말한다. 재미있는 학습 경험을 먼저 보여주고, 부모가 신뢰할 근거를 이어서 설명한다.
- 코드 먼저 구현한다. 앱의 실제 캐릭터와 화면을 사용한다. buildPath: code.
- 제작자는 중학교 2학년 아들을 위해 제대로 된 한자 앱을 만들기 시작했다. 아들의 실제 피드백을 수없이 받아 수정했다.
- 아들이 급수를 정복할 때까지 계속 개선하겠다는 제작자의 개인적 약속을 전달한다.
- 직접 쓰기, 성취감, 친근한 캐릭터, FSRS 복습, 연상, 어휘 예문, 급수 시험 알림을 설명한다.
- 다른 한자 앱의 실제 낮은 평가에서 나타난 불편을 출처와 함께 요약한다. 후기를 지어내거나 전체 이용자의 의견으로 일반화하지 않는다.

## 구현과 출시 상태

기존 정적 HTML/CSS/JS와 GitHub Pages Actions 배포를 유지한다. iOS·Android 스토어 출시 전이며 공개 웹 베타가 있다. 스토어 다운로드 링크와 출시일을 만들지 않는다. 모바일 알림과 웹 체험의 범위를 구분한다.

## 제품 근거

동일 Sunworks 프로젝트의 `apps/hanja-study-app` 문서와 코드: README.md, PRODUCT.md, CLAUDE.md, docs/decisions/adr-hard-paywall-2026-10-01.md, docs/plans/plan-release-final-2026-10-01.md, lib/srs/srs_service.dart, lib/exam/exam_alert_plan.dart, lib/services/notification_service.dart, 단어 데이터 파이프라인 문서. 최신 결정과 실제 구현이 과거 기획보다 우선한다.

- FSRS 기반 복습 간격 조절, 능동적 회상, 손글씨와 획순, 연상과 예문을 결합한다. 앱 자체의 학습 효과를 임상적으로 검증했다는 주장은 하지 않는다.
- 사전의 정확한 명칭은 **한국어기초사전**, **표준국어대사전**이다. 수록 어휘와 학습 예문을 구분한다.
- 호랑·까치와 또또·구름이·왜왜·앗차의 기존 그림을 활용한다. 버려진 ‘한자마다 새로운 생물 수집’ 기획이나 전 급수 완성 주장을 하지 않는다.
- 시험 일정 확인과 모바일 알림을 설명한다. 웹에는 네이티브 로컬 알림 기능이 없다.
- 최신 출시 가격 계획은 가입·카드 등록 없는 3일 체험 후 29,900원 일회성 구매이다. 결제는 출시 준비 중이며 현재 웹 베타와 구분한다.
- 연락처: support@sunworks.kr. 회사 사이트: https://www.sunworks.kr/.

## 콘텐츠 원칙

제작자의 이야기에는 확인된 사실만 사용한다. 아들의 직접 인용, 성적, 합격 실적, 사용자 수, 앱 평점, 효과 배율을 만들지 않는다. 연상 예시는 기억을 돕는 설명이지 한자의 역사적 어원을 단정하는 설명이 아니다. 기억 간격 그래프는 원리 설명이며 실제 개인의 예측값으로 표시하지 않는다.

## 성공 기준

첫 화면에서 한자 앱임을 이해하고 간단한 학습 체험을 해볼 수 있다. 학생은 재미와 성취를, 부모는 내용·설계·개발 의지를 이해한다. 모바일·키보드·모션 감소 환경에서 콘텐츠와 체험이 작동하고, 실제 웹앱으로 연결된다.
