## 적용한 검색 설정

- 기존 검색 제목·H1의 브랜드/한자 공부 앱/급수 범위를 유지했다. 검색 메타 설명과 공유용 OG에는 제작 배경·학습 방식·실제 체험 및 구매 조건을 넣었다.
- `WebPage` 메타 설명은 HTML에서 읽고, `dateModified`와 홈 사이트맵 `lastmod`는 실제 수정일 2026-11-11로 맞췄다. 수정하지 않은 급수 페이지의 날짜는 그대로 둔다.
- `SoftwareApplication.creator`에 본문에 공개한 남선과 썬웍스의 관계를 연결했다. `featureList`는 실제 화면의 학습 기능·수록 범위와 일치시켰다. 허위 평점·추천·효과 수치를 넣지 않았다.
- 질문·답변은 보이는 FAQ에서 추출해 JSON-LD와 llms 두 파일을 생성한다. 본문과 별개의 검색용 답변을 만들지 않는다.
- canonical, 검색·AI 크롤러를 허용하는 robots.txt, 급수별 페이지와 시험 일정 내부 링크는 기존 설정을 유지한다.
- 새 문구의 글꼴 서브셋을 재생성하고 CSS·글꼴 캐시 버전을 갱신했다.

## 다음 설정 우선순위

1. **검색 수집 확인:** 배포 후 Search Console의 홈 URL 검사에서 실제 HTML·선언/선택 canonical·색인 상태를 확인하고 갱신 요청. sitemap.xml 제출 상태도 확인한다. 네이버 서치어드바이저와 Bing Webmaster Tools 역시 등록·수집 상태를 확인한다. 이번 작업에서 계정 내 제출 상태를 확인하거나 변경하지는 않았다.
2. **검색 의도별 콘텐츠:** 홈은 브랜드와 앱 선택, `/grades/8/`은 첫 독학, `/grades/3/`은 중학생 목표, `/grades/2/`는 읽기·쓰기 준비, `/exam-schedule/`은 접수 일정에 집중한다. GSC에서 실제 노출되는 질문을 보고 각 페이지의 공부 계획과 실전 예시를 보강한다. 같은 키워드의 얇은 페이지를 여러 개 만들지 않는다.
3. **전환 측정:** PostHog에서 `$host = hanja.sunw.kr`로 한정하고 QA 캠페인 `seo_20261110`, `deployment_check` 유입을 제외한다. App Store 클릭·Google Play 클릭·웹 체험 클릭을 별도 전환 목표로 정의한다. 기존 autocapture에 해당 클릭이 있는지 확인하고, 없을 때만 최소 이벤트를 추가한다. 스토어 이동은 설치 완료가 아니므로 설치 수는 각 스토어 지표와 별도로 보고한다. 이번 수정에는 추적 코드 변경이 없다.
4. **AI 인용 재확인:** 동일한 한국어 질문을 Google AI 모드·ChatGPT 검색·Perplexity에 반복해 날짜, 질문, 답변, 인용 URL, 제작자·가격·급수의 오류를 기록한다. 브랜드 지정 질문과 ‘초등학생 한자 8급 독학 앱’ 같은 일반 질문을 분리한다. 답변에 앱명이 나오는 것과 링크를 인용하는 것도 구분한다.

배포일을 D로 잡아 D+14와 D+28에 측정한다. 11월 11일 배포 시 11월 25일과 12월 9일이다. Search Console에서는 브랜드/일반 검색어별 노출·클릭·CTR과 페이지별 색인 상태를, PostHog에서는 검색 유입의 스토어/웹 체험 클릭률을 본다. 적은 표본·계절성·검수 유입이 있으므로 변경 전후 차이를 바로 인과 효과로 해석하지 않는다. 예약 작업은 생성하지 않았다.

## 현재 공식 지침에 따른 범위

- [Google AI 기능 안내](https://developers.google.com/search/docs/appearance/ai-features): AI 개요·AI 모드는 기본 SEO와 색인·스니펫 자격이 중요하다. 별도의 AI 전용 파일이나 특수 스키마는 필수가 아니다. llms.txt는 보조 설명으로 유지하며, 학습·인용·우선 추천을 보장하는 장치로 설명하지 않는다.
- [Google 문서 변경 기록](https://developers.google.com/search/updates#removing-faq-rich-result): FAQ 리치 결과는 2026년 5월 지원 종료 후 관련 문서가 삭제됐다. FAQ와 Schema.org 마크업은 읽기 쉬운 답변과 의미 표현을 위해 유지한다. Google의 FAQ 검색 확장을 약속하지 않는다.
- 두 자료와 [FSRS 공식 설명](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/ABC-of-FSRS)은 2026-11-11 ego-lite TaskSpace 33에서 확인했다.
