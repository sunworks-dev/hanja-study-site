한눈에 보기

이 앱의 학습 기능은 이름, 전화번호, 이메일 주소 같은 개인정보를 모으지 않아요. 직접 보내는 문의는 10절에서 설명해요.

회원가입도 로그인도 없어요. 공부한 기록은 여러분의 기기 안에만 남아요.

우리는 그 기록을 볼 수 없고, 다른 곳으로 보내지도 않아요.

연구에 참여하기로 한 경우에만, 학습 횟수를 모은 파일을 직접 보낼 수 있어요(9절).

1. 우리가 모으는 개인정보

학습 기능은 개인정보를 모으거나 다른 사람에게 주지 않아요. 연구 참여·의견 보내기·문항 신고에서 직접 보내는 정보는 아래에서 따로 설명해요.

광고도 없고, 사용자를 따라다니며 기록하는 추적 도구도 넣지 않았어요.

연구 참여자가 직접 보내 준 집계 파일은 9절에서 따로 설명해요.

의견 보내기로 직접 적어 보낸 이름 또는 별칭, 이메일과 문의 내용은 10절에서 따로 설명해요.

2. 학습 기록은 어디에 저장되나요

어떤 한자를 언제 맞혔는지, 며칠 연속으로 공부했는지 같은 학습 기록은 앱을 설치한 기기 안에만 저장돼요.

휴대전화와 태블릿처럼 기기가 여러 대면 기록은 서로 따로 쌓여요. 기기끼리 기록을 합치는 기능은 아직 없어요.

웹 브라우저에서 쓰면 기록은 그 브라우저의 저장 공간에 남아요. 브라우저 기록을 지우거나 시크릿 모드로 열면 학습 기록도 사라질 수 있어요.

3. 알림 권한은 왜 필요한가요

정해 둔 시간에 "공부할 시간이야"라고 알려 주기 위해서만 써요. 시험 날짜가 다가오면 남은 날을 알려 주는 데에도 써요.

알림은 기기 안에서 만들어져요. 알림을 만들려고 외부 서버에 무언가를 보내지 않아요.

알림을 받고 싶지 않으면 설정에서 끄거나, 기기의 알림 권한을 꺼도 앱은 그대로 쓸 수 있어요.

4. 기기 자동 백업

iPhone의 iCloud 백업이나 Android의 자동 백업을 켜 두면, 운영체제가 앱 데이터를 백업에 함께 담을 수 있어요.

이 백업은 애플이나 구글이 여러분의 계정에서 관리하는 것이고, 우리가 그 내용을 보거나 가져올 수는 없어요.

백업에 담기지 않게 하려면 기기 설정에서 이 앱의 백업을 꺼 주세요.

5. 인터넷을 쓰는 순간

앱은 시험 일정과 학습 자료를 최신으로 유지하려고 정해진 주소에서 버전 목록과 바뀐 자료를 내려받아요. 자료에는 한자·이야기·그림·음성이 포함될 수 있어요. 받은 자료는 기기에 저장해 인터넷 없이도 쓸 수 있어요. 웹에서는 새 버전이 나왔는지 확인하는 파일도 함께 확인해요.

이때 보내는 건 "그 파일을 주세요"라는 요청뿐이에요. 학습 기록이나 기기 안의 정보는 함께 보내지 않아요.

다만 인터넷 요청은 그 파일을 보관하는 호스팅 회사의 서버를 거치기 때문에, 접속 시각과 IP 주소 같은 접속 기록이 그 회사 쪽에 잠시 남을 수 있어요. 이 기록은 우리가 만들지도 보관하지도 않아요.

6. 기록을 내보낼 때

"자랑하기"에서 만든 기록증 이미지나 학습 기록 파일은 여러분이 직접 내보낼 때만 기기 밖으로 나가요.

내보내기를 누르면 기기의 공유 창이 열리고, 거기서 고른 앱(메시지, 사진첩 등)으로만 전달돼요. 우리 서버로는 아무것도 가지 않아요.

기록증 이미지에는 이름이나 연락처가 들어가지 않아요.

7. 보관 기간과 지우는 방법

학습 기록은 여러분이 지울 때까지 기기에 남아요. 우리가 따로 정한 보관 기간은 없어요.

기록을 지우려면 두 가지 방법이 있어요.

  • 설정 화면의 "학습 기록"에서 기록 초기화를 누르면 학습 기록이 지워져요.
  • 앱을 삭제하면 앱이 만든 데이터가 기기에서 함께 사라져요.

기기 자동 백업에 이미 담긴 내용은 기기 설정의 백업 관리에서 지워 주세요.

8. 만 14세 미만 어린이와 보호자에게

이 앱은 초등학생과 중학생이 한자를 공부하도록 만들었어요. 개인정보를 모으지 않으니 가입할 때 보호자 동의를 받는 절차도 없어요. 연구 참여는 예외예요. 모집할 때 보호자 동의를 먼저 받아요(9절).

보호자께서는 자녀의 기기에서 앱 설정과 학습 기록을 직접 확인하고 지울 수 있어요.

나중에 계정이나 동기화 기능이 생겨서 개인정보를 다루게 되면, 그때는 법에 따라 보호자 동의를 먼저 받고 이 방침도 미리 고쳐서 알려 드릴게요.

9. 연구 참여(선택)

앱을 더 좋게 만들려고, 운영자가 미리 모집한 참여자에게서만 학습 횟수를 모은 파일을 받아요. 참여는 선택이고, 참여하지 않아도 앱의 모든 기능을 그대로 쓸 수 있어요.

만 14세 미만 참여자는 모집할 때 보호자(법정대리인)에게 먼저 동의를 받아요. 앱도 파일을 보내기 전에 "보호자 동의를 받은 참여자만" 보내 달라고 한 번 더 알려요.

파일에 담기는 것은 운영자가 나눠 준 참여 코드, 목표 급수, 첫 학습일부터 며칠째인지를 센 날짜 번호와 그날의 학습 시작·완료 같은 동작 횟수, 급수를 완성하거나 모의시험에 처음 합격한 날과 파일을 만든 날의 날짜 번호, 캐릭터 표시 실험 배정값(켜짐/꺼짐)뿐이에요. 실제 날짜와 시각, 답안, 한자별 기록, 이름과 연락처, 기기 식별값은 담기지 않아요.

파일은 설정 화면의 "학습 기록 → 연구 참여"에서 직접 공유 창을 열어 보낼 때만 기기 밖으로 나가요. 앱이 저절로 보내는 일은 없어요.

참여 코드는 기기 안에만 저장되고 학습 기록 백업 파일에는 들어가지 않아요. "연구 참여"에서 지우거나 학습 기록을 초기화하면 함께 지워져요. 모집할 때 받은 연락처는 집계 파일과 따로 보관해요. 참여 코드와 연락처를 잇는 명단은 운영자만 봐요. 캐릭터 표시 실험 배정값(켜짐/꺼짐)은 참여 코드를 지우거나 학습 기록을 초기화해도 기기에 남아서, 같은 코드를 다시 넣으면 원래 배정으로 돌아가요.

보관 기간: 집계 파일은 연구가 끝난 뒤 1년 안에 지워요. 연락처와 참여 코드 명단은 연구가 끝나면 바로 지워요. 참여를 그만두거나 보낸 파일을 지워 달라고 하려면 참여 코드와 함께 아래 문의처로 알려 주세요.

10. 의견 보내기

설정의 "의견 보내기"나 이용권 화면의 "문의하기"에서 이름 또는 별칭, 답장 받을 이메일, 문의 종류와 내용을 직접 적어 보낼 수 있어요. 보내기를 누르고 보안 확인을 마친 경우에만 썬웍스 지원 이메일(support@sunworks.kr)로 전달돼요.

학습 기록은 보내지 않아요. 앱 버전과 데이터 버전 같은 진단 정보는 기본으로 꺼져 있고, 함께 보내기를 직접 선택한 경우에만 문의 본문에 들어가요.

문의 전달과 스팸 방지에는 Cloudflare Workers·Turnstile, Resend, Google Workspace를 이용하며 국외에서 처리될 수 있어요. 봇·중복·과도한 발송 방지를 위해 IP·이메일 해시와 요청 식별정보를 일시적으로 처리해요. 해시도 개인정보로 취급해요.

문의에 필요한 정보만 적고 민감정보는 보내지 마세요. 만 14세 미만 어린이의 개인정보가 포함된 문의는 보호자가 대신 보내 주세요.

접수 결과가 불확실하면 이 화면에서 보안 확인 후 같은 내용으로 다시 보내 주세요. 새로 작성하면 중복 접수될 수 있어요. 계속 실패하거나 삭제를 문의하려면 support@sunworks.kr로 알려 주세요.

받은 의견과 이메일은 답변과 앱 개선에만 써요. 메일함과 제공자의 보관·삭제 기간은 별도 운영 정책으로 정할 예정이에요.

소개 사이트의 체험 정보

이 사이트에는 회원가입·로그인·주문·결제·파일 업로드 기능이 없습니다. 문의는 별도 보안 문의폼으로 연결합니다. 소개 페이지에서 그린 손글씨와 체험 결과는 저장하거나 전송하지 않습니다. 어떤 버튼과 링크를 눌렀는지는 아래 방문 통계에 기록될 수 있습니다.

체험 상태는 페이지를 여는 동안 브라우저 메모리에서만 사용하며, 새로고침하거나 페이지를 닫으면 초기화됩니다. 소개 체험을 앱의 학습 기록으로 저장하지 않습니다.

광고 SDK와 추적 쿠키는 없습니다. 아래 방문 통계 도구도 쿠키와 브라우저 저장소를 쓰지 않습니다. 소개 사이트 코드는 체험 기록을 쿠키·로컬 저장소에 보관하지 않습니다. 브라우저의 일반적인 파일 캐시는 체험 기록과 별개입니다.

방문 통계

사이트를 어떻게 이용하는지 알고 개선하기 위해 PostHog Inc.의 방문 통계 서비스(PostHog Cloud EU)를 사용합니다. 쿠키와 브라우저 저장소를 쓰지 않으며, 이름·연락처·로그인 정보처럼 사람을 알아볼 수 있는 정보를 보내지 않습니다. 같은 사람이 다른 날 다시 방문해도 서로 연결하지 않습니다.

호스팅 과정의 접속정보

이 사이트의 파일은 Cloudflare, Inc.의 Cloudflare Pages에서 제공합니다. Cloudflare는 사이트를 전송하고 공격을 막기 위해 방문자의 IP 주소와 접속 시각, 요청한 주소 같은 요청 정보를 처리합니다. 따라서 이 사이트를 방문할 때 어떤 개인정보도 처리되지 않는다는 의미는 아닙니다.

썬웍스는 방문자별 IP 로그를 별도로 수집하는 기능을 운영하지 않습니다. Cloudflare가 처리하는 정보의 범위·보관·권리 행사와 미국 등 해외 처리에 관한 내용은 Cloudflare의 공식 개인정보 처리방침에서 확인할 수 있습니다. 공개 문서에 없는 구체적인 보관 일수는 임의로 정하지 않습니다.

문의폼이나 이메일로 문의할 때

보안 문의폼은 Cloudflare Workers와 Turnstile로 접수와 봇 검증을 처리하고, Resend로 운영자 알림과 고객 접수 확인 메일을 발송합니다. 입력한 이름(별칭 가능), 이메일, 제목과 내용은 문의 확인·답변을 위해 support@sunworks.kr의 Google Workspace 메일함에 전달됩니다. 고객 접수 확인 메일에는 문의 내용이 포함되지 않습니다.

이 과정에서 Cloudflare·Resend·Google을 통해 정보가 처리되며 국외에서 처리될 수 있습니다. 문의폼은 학습 기록을 자동으로 첨부하지 않습니다. 봇·중복·과도한 발송 방지를 위해 IP·이메일의 해시와 요청 식별정보를 일시적으로 처리합니다.

기존 이메일 링크는 이용자의 메일 앱을 엽니다. 이용자가 직접 전송하면 발신자 주소와 이름, 본문·첨부파일의 정보가 전달될 수 있습니다.

문의에는 문제 확인에 필요한 최소한의 정보만 담아 주세요. 만 14세 미만 어린이의 개인정보가 포함된 문의는 보호자가 대신 보내 주세요.

문의 정보의 이용과 보관은 위 앱 처리방침 10절과 같은 기준을 따릅니다. 문의 방법은 고객지원에서 확인해 주세요.

다른 서비스로 이동할 때

웹앱·회사 홈페이지·공식 자료 링크를 누르면 해당 서비스로 이동합니다. 이동한 서비스에는 그 서비스의 개인정보 처리방침이 적용됩니다. 소개 페이지에 있는 영상·그림·글꼴은 이 사이트에서 직접 제공하며, 외부 동영상 플레이어를 삽입하지 않습니다.
