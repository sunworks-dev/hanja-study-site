소개 사이트의 체험 정보

이 사이트에는 회원가입·로그인·주문·결제·파일 업로드·문의 입력 폼이 없습니다. 소개 페이지의 한자 연결, 손글씨, 어휘 탭과 영상 조작 기록을 썬웍스 서버에 전송하지 않습니다.

체험 상태는 페이지를 여는 동안 브라우저 메모리에서만 사용하며, 새로고침하거나 페이지를 닫으면 초기화됩니다. 소개 체험을 앱의 학습 기록으로 저장하지 않습니다.

썬웍스가 설치한 광고 SDK, 방문자 분석 도구, 추적 쿠키는 없습니다. 소개 사이트 코드는 체험 기록을 쿠키·로컬 저장소에 보관하지 않습니다. 브라우저의 일반적인 파일 캐시는 체험 기록과 별개입니다.

호스팅 과정의 접속정보

이 사이트의 파일은 GitHub, Inc.의 GitHub Pages에서 제공합니다. GitHub는 공식 문서에서 Pages 방문자의 IP 주소를 보안 목적으로 기록·보관한다고 안내합니다. 따라서 이 사이트를 방문할 때 어떤 개인정보도 처리되지 않는다는 의미는 아닙니다.

썬웍스는 방문자별 IP 로그를 별도로 수집하는 기능을 운영하지 않습니다. GitHub가 처리하는 정보의 범위·보관·권리 행사와 미국 등 해외 처리에 관한 내용은 GitHub의 공식 개인정보 처리방침에서 확인할 수 있습니다. 공개 문서에 없는 구체적인 보관 일수는 임의로 정하지 않습니다.

  • GitHub Pages의 IP 주소 수집 안내
  • GitHub 개인정보 처리방침

이메일로 문의할 때

문의 링크는 이용자의 메일 앱을 엽니다. 사이트가 대신 메일을 보내지 않으며, 이용자가 직접 전송해야 문의가 전달됩니다. 이메일을 보내면 발신자 주소와 이름, 본문·첨부파일에 적은 정보가 수신자에게 전달될 수 있습니다.

문의에는 문제 확인에 필요한 최소한의 정보만 담아 주세요. 만 14세 미만 어린이의 개인정보가 포함된 문의는 보호자가 대신 보내 주세요.

앱 이용에 관한 기존 처리방침과 문의처를 함께 제공합니다. 문의 메일의 세부 처리·보관 기준과 개인정보 보호 담당자 정보는 실제 운영 절차를 확인해 별도로 안내할 예정이며, 이 페이지를 완성된 문의 처리방침으로 대신하지 않습니다.

다른 서비스로 이동할 때

웹앱·회사 홈페이지·공식 자료 링크를 누르면 해당 서비스로 이동합니다. 이동한 서비스에는 그 서비스의 개인정보 처리방침이 적용됩니다. 소개 페이지에 있는 영상·그림·글꼴은 이 사이트에서 직접 제공하며, 외부 동영상 플레이어를 삽입하지 않습니다.

안내 범위와 근거

앱의 공식 처리방침을 변경하거나 연구 참여 동의를 받는 페이지가 아닙니다. 개인정보 처리방침의 필수 내용은 개인정보 보호법 제30조, 단말 내부 처리와 외부 서버 처리를 구분하는 안내는 개인정보보호위원회의 2026년 작성지침 개정 안내를 확인했습니다.
